# 🔐 Aarav Mehta — Cybersecurity Portfolio 🛡️

## 📌 Overview

A modern, interactive portfolio for a cybersecurity professional specializing in penetration testing and security engineering.  

Showcases security services, case studies, technical expertise, professional experience, and client testimonials.

---

## 🛡️ Description

Designed with a clean interface, a consistent navy and teal color palette, and subtle security-inspired visuals.  

Features animations, interactive components, and smooth navigation for an engaging browsing experience.  

Built with Next.js, Tailwind CSS, Framer Motion, and shadcn/ui for a responsive and polished user experience.
